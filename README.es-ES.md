# CS_Decrypt

> Script de descifrado de tráfico de CobaltStrike

Solo es necesario modificar el siguiente contenido dentro del archivo `cs_decrypt.py`. Para más información, visita https://5ime.cn/cobaltstrike-decrypt.html

```
file_path = "Ruta a .cobaltstrike.beacon_keys"
encode_data = "Metadatos"
encrypt_data = "Datos de tarea"
```
